04 / CÁCH CÀI ĐẶT

Cài nhanh trong 3 bước đơn giản

  1. BƯỚC 1

    Tải bộ cài mới nhất

    Thoát game nếu đang mở, sau đó nhấn nút tải ở mục Tải về để lấy tệp MCSM-Vietnamese-Setup.exe từ bản phát hành mới nhất.

  2. BƯỚC 2

    Chọn thư mục game & Cài

    Mở tệp vừa tải, chọn đúng thư mục cài Minecraft: Story Mode trên máy bạn, giữ nguyên các mục đã tích sẵn rồi nhấn Tiếp → Cài đặt.

  3. BƯỚC 3

    Bật phụ đề & Thưởng thức

    Mở game, vào Cài đặt → Âm thanh / Hình ảnh rồi bật Phụ đề để có trải nghiệm tốt hơn. Bạn có thể bật/tắt nút bỏ qua tóm tắt hoặc Discord trong Cài đặt → Lối chơi, hoặc mở lại bộ cài chọn Gỡ bản Việt hóa để về tiếng Anh gốc.

LƯU Ý NHỎ

Nếu Windows hiện cảnh báo Windows protected your PC khi mở tệp cài (do đây là bản Việt hóa cộng đồng miễn phí chưa mua chứng thư ký số thương mại), bạn chỉ cần nhấn More info → Run anyway để tiếp tục cài đặt.
